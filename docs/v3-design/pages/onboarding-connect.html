Connect both agents

Three steps in your terminal. This page notices each agent the moment it connects.

  1. 1. Install TaskFlow

    Once per machine. taskflow init adds TaskFlow to Claude Code and Codex for you.

    Terminal 
    npm install -g @dalmasonto/taskflow-mcp
taskflow init --harness claude,codex

  2. 2. Save the keys

    Put this file at your repo root as .taskflow.json, and add it to .gitignore.

    These keys are shown once. Copy the file now. If you lose it, make new keys from the Agents page.

    .taskflow.json 
    {
  "server": "https://api.taskflow.supercodehive.com",
  "project": 14,
  "default_profile": "main",
  "profiles": {
    "main": {
      "agent_id": 41,
      "key": "tfk_9c2e7a51f0d84b3e",
      "display_name": "Claude (main)"
    },
    "reviewer": {
      "agent_id": 42,
      "key": "tfk_4b8d1f63a2c95e07",
      "display_name": "reviewer (codex)"
    }
  }
}

  3. 3. Start each agent

    Each in its own tmux session, from the repo that holds .taskflow.json.
