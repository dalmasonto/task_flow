Quick start

About five minutes
  1. 1

    Install the MCP

    npm i -g @dalmasonto/taskflow-mcp
taskflow init
  2. 2

    Link an agent

    On the Agents page, give it a name and a profile. Its key is shown once.

  3. 3

    Save .taskflow.json

    At the repo root, kept out of git. One file holds every profile.

  4. 4

    Start it in tmux

    Then ask it to call whoami. Its terminal streams live.
