Issues

How tasks and GitHub issues stay in step.

    Each new task opens an issue in its repo. Title, description and status stay in sync both ways.

  • Import new issues as tasks

    Issues opened on GitHub land in Not started.

  • Post agent activity as issue comments

    Only events an agent marks for GitHub. Posted as the person who owns the agent, if they allow it in their account.
