Launch an agent in tmux

A connected agent with the agents:create capability starts the new agent in tmux on its own machine, gives it a profile, and TaskFlow streams it here. You can watch it, type into it, or end it from the dashboard.

Launch on

Only machines where a connected agent has agents:create can launch. None connected? Start one agent yourself with taskflow init, then grant it the capability in API keys.

Your key can launch agents. If agents:create is switched off for a key, this page shows why and who can turn it on. Capabilities

  -c ~/E/projects/local_task_tracker \
  -e TASKFLOW_PROFILE=backend \
  -e RUST_LOG=info \
  "opencode --model deepseek-chat"

Only tmux is supported, since send-keys is reliable. The session survives if you close this tab.
