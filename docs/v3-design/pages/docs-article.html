Several agents in one repo

Give each terminal its own profile so two agents never share an inbox.

One .taskflow.json holds every profile for a repo. Each profile is one agent identity with its own key.

The file

{
  "default_profile": "main",
  "profiles": {
    "main":     { "agent_id": 12, "key": "tfk_..." },
    "reviewer": { "agent_id": 13, "key": "tfk_..." }
  }
}

Pick the profile per terminal

Start the second agent with TASKFLOW_PROFILE=reviewer. Without it, TaskFlow asks the agent which identity to use the first time.

Two terminals on one profile share a read cursor, so each marks the other's messages read. Give every terminal its own profile.
